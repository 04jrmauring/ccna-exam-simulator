1. Switching, VLANs, STP & CDP/LLDP Cheat Sheet

! VLAN Creation & Access Port
vlan 10 -> name SALES
int fa0/1 -> sw mo ac -> sw ac vl 10
int fa0/5 -> sw vo vl 20

! 802.1Q Trunk & Native VLAN
int gi0/1 -> sw mo tr
  sw tr na vl 99
  sw tr al vl 10,20

! EtherChannel (LACP & PAgP)
int range gi0/1 - 2 -> ch 1 mo active (or passive)
int range gi0/1 - 2 -> ch 2 mo desirable (or auto)
int po1 -> sw mo tr

! STP Root, PortFast & BPDU Guard
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary (or secondary)
int fa0/1 -> spanning-tree portfast
             spanning-tree bpduguard enable

! CDP & LLDP Control
cdp run | no cdp run | cdp timer 30 | cdp holdtime 120
lldp run | lldp timer 30 | lldp holdtime 120
int gi0/1 -> no cdp enable | lldp transmit | lldp receive

2. Routing & IP Connectivity Cheat Sheet

! Inter-VLAN: Router-on-a-Stick (ROAS)
int gi0/0 -> no sh
int gi0/0.10 -> enc dot1q 10
  ip add 192.168.10.1 255.255.255.0

! Inter-VLAN: Layer 3 Switch (SVI)
ip routing
int vlan 10 -> ip add 192.168.10.1 255.255.255.0 -> no sh
int gi0/1 -> no switchport -> ip add 10.0.0.2 255.255.255.252

! Static, Host (/32, /128) & Floating Routes
ipv6 unicast-routing
ip route 0.0.0.0 0.0.0.0 203.0.113.2
ip route 0.0.0.0 0.0.0.0 198.51.100.2 5
ip route 172.16.99.10 255.255.255.255 10.1.1.2
ipv6 route 2001:db8:99::10/128 2001:db8:12::2
ipv6 route ::/0 2001:db8:13::2 5

! Single-Area OSPFv2 & Troubleshooting
router ospf 1
  router-id 1.1.1.1
  network 10.0.0.0 0.0.255.255 area 0
  passive-interface gi0/1 (fix: no passive-interface gi0/0)
  default-information originate
  auto-cost reference-bandwidth 10000
int gi0/0 -> ip ospf 1 area 0 | ip ospf priority 200
             ip ospf network point-to-point

3. IP Services, Security & SSH Hardening Cheat Sheet

! NAT / PAT Overload
access-list 1 permit 10.10.0.0 0.0.255.255
int gi0/0 -> ip nat inside | int gi0/1 -> ip nat outside
ip nat inside source list 1 int gi0/1 overload

! DHCPv4 Server & Relay
ip dhcp excluded-address 192.168.30.1 192.168.30.10
ip dhcp pool BRANCH_LAN -> network 192.168.30.0 255.255.255.0
  default-router 192.168.30.1 | dns-server 8.8.8.8
int gi0/0 -> ip helper-address 10.0.0.1

! Extended & Standard ACLs
access-list 100 deny tcp 192.168.10.0 0.0.0.255 host 10.10.50.10 eq 80
access-list 100 permit ip any any
int gi0/0 -> ip access-group 100 in

! Port Security (Protect / Restrict / Shutdown) & Snooping/DAI
int fa0/3 -> sw mo ac -> sw po -> sw po max 2
  sw po mac st -> sw po vio protect|restrict|shutdown
ip dhcp snooping | ip dhcp snooping vlan 10 | ip arp inspection vlan 10

! Device Hardening (Full SSHv2)
hostname R1-EDGE | enable secret CiscoEn123 | service password-encryption
ip domain-name corp.local | username admin secret CiscoAdm123
crypto key generate rsa modulus 2048 | ip ssh version 2
line vty 0 15 -> login local | transport input ssh
